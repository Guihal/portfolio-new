# Ozon Logistics API

Backend for integrating a Tilda e-commerce site with Ozon delivery infrastructure. Built with Bun/Elysia/TypeScript, featuring OAuth authorization against Ozon Seller API, delivery cost calculation, pickup point (PVZ) selection with map, courier delivery, and order creation from Tilda webhooks.

## What it does

- **OAuth flow** with Ozon Seller API (token refresh, retry on 401)
- **Delivery calculation** — cost & time estimates via Ozon API
- **PVZ cache** with FTS5 search and cron refresh (addresses Russia-wide)
- **Order creation** triggered by Tilda checkout webhooks
- **Rate limiting** at 10 req/s to Ozon API
- **Geocoding** via Yandex Geocoder + Nominatim fallback
- **Email alerts** on failures via SMTP
- **JS patch** injected into Tilda cart for seamless frontend integration
