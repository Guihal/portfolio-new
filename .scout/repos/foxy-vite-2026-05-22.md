# foxy-vite / BasedPack

**Status:** NOT FOUND on GitHub (local-only)

**Local path:** `/usr/projects/tilda/foxy-vite`

## What it is

A custom Vite-based build system for Tilda landing pages. Named "BasedPack" in `package.json`. Designed to compile multi-page static sites from EJS templates + SCSS into production-ready bundles.

## Architecture & Stack

- **Vite 7.2** with custom `vite.config.ts` — multi-entry rollup build
- **TypeScript** — full TS config and tooling
- **EJS templating** — custom Vite plugin (`vite-plugin-ejs-preprocess`) renders EJS includes
- **SCSS + PostCSS** — `postcss-preset-env`, `autoprefixer`, `cssnano` for CSS pipeline
- **Terser** — JS minification in production
- **Multi-page builds** — `PAGE=index|catalog|product|linked` env-filter for selective compilation
- **Asset routing** — deterministic output paths (`css/`, `js/`, `assets/images/`)
