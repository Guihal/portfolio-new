## Summary

**UCKLAD** is a client Tilda-integrated project built with a custom Vite-based build pipeline. The repo contains a multi-page site builder (`main`, `product` pages) that compiles to Tilda-compatible output. Despite being a single-commit project, it demonstrates a sophisticated frontend build setup.

## What it does

- Custom Vite 7 build system for Tilda-integrated multi-page sites
- Page-specific builds via `PAGE=main` / `PAGE=product` env variables
- SCSS preprocessing with global vars/mixins/functions injection
- EJS templating with per-page HTML entry points
- PostCSS pipeline with autoprefixer and cssnano (with calc preservation for fluid layouts)
- Asset optimization with custom Rollup output paths (images → `assets/images/`, CSS → `css/`, JS → `js/`)
- Input masking via `imask`
- Web worker pools via `tinypool` + `greenlet`
- Build counter tracking via custom Vite plugin

## Directory structure

- `src/` — TypeScript/SCSS source
- `src/html/pages/` — EJS page templates (multi-entry)
- `app/` — Build output
- `tilda/` — Tilda integration assets
- `html-site/` — Static HTML export
- `plugins/` — Custom Vite plugins (build counter)
