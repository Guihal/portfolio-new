# RTK QR Front

Фронтенд-приложение для сервиса «Точка Входа» РТК — генерация анимированных QR-кодов с эффектом «дыхания» для авторизованных пользователей.

## What it does

- Генерация QR-кодов с волновой анимацией пульсации
- Система авторизации и регистрации пользователей
- Анимированный прелоадер при загрузке приложения
- Защита маршрутов (route guards)
- Поддержка мобильных платформ (iOS/Android) через Capacitor
- WebSocket-интеграция для real-time обновлений QR-кодов
- Privacy screen и secure storage для защиты данных
