# subbrain

**Subbrain — Цифровая команда** ("Second Brain") is an OpenAI-compatible proxy with autonomous agents and long-term memory. This is Dmitry's (Guihal) primary architecture project and the backbone of his AI/infra work.

## What it does

- OpenAI-compatible API proxy with model routing across multiple providers (NVIDIA NIM, MiniMax, OpenRouter, DeepSeek)
- Autonomous agent pipeline with virtual roles (teamlead, critic, architect)
- 4-layer memory system (focus, context, shared, archive)
- BAML-based arbitration synthesis and promptfoo regression testing
- Docker-compose deployment with bifrost side-car
- VS Code extension for inline integration
- Web UI with SSE streaming, cancel button + AbortController plumbing
