# ------ (Task Companion)

**Task Companion** — diploma project: mobile offline-first task manager with light gamification. MVP-0 completed (15/15 packets). Working core includes tasks, XP, levels, and SQLite.

## What the repo does

A cross-platform task management application built with modern web technologies and wrapped for Android via Capacitor. The app features:

- **Task management** — create, edit, complete, archive tasks
- **Smart complexity** — automatic ordered decision tree + manual adjustment
- **Task grouping** — overdue → nearest → no deadline → completed
- **Profile / XP system** — earn XP for completing tasks, level progression
- **Offline-first** — SQLite local storage via @capacitor-community/sqlite
- **Clean Architecture** — Hexagonal / Ports & Adapters pattern

## Architecture highlights

Hexagonal / Ports & Adapters architecture with clean domain core:

- UI (Vue pages, components)
  → Store (Pinia — thin, state + use case calls)
    → Use Case (business operation)
      → Port / Repository Interface
        → Infrastructure (SQLite / memory / capacitor / system)

Strict rules: UI doesn't import infrastructure/*, Store contains no business logic, Use cases receive dependencies via arguments (no global container), Domain is pure TypeScript without framework dependencies.
