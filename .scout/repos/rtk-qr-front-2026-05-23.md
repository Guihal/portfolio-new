# rtk-qr-front

Frontend application for «Точка Входа» (RTK) service — generating animated QR codes with a "breathing" pulse effect for authenticated users.

## What it does
- Generates QR codes with wave pulsation animation
- Full auth system (login / register)
- Animated preloader on app load
- Route guards for protected pages
- Mobile support via Capacitor (iOS/Android builds)
- Privacy screen & secure storage composables
- WebSocket integration for QR state sync
